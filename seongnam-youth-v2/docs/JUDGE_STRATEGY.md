# 심사위원 관점 고득점 전략 (경제 파트 제거 버전)

## 1. 심사 포인트 재정의
- 인사이트: "청년 유출이 어디서 발생하고 어디로 향하는가"를 동 단위로 정밀 제시
- 방법론: 상관계수 + p-value + 부트스트랩 CI + 민감도 분석으로 주장 강도 분리
- 정책 활용성: 단순 시각화가 아니라 즉시 개입 대상 우선순위(A/B/C/D)까지 제시
- 재현성: `run_all.ps1` 1회 실행으로 동일 산출 재생성

## 2. 본 v2에서 실제 반영한 개선
- 경제 변수(벤처/가맹점) 완전 삭제
- 민원강도 공식 지표를 `총인구 1천명당`으로 교정
- 행선지를 정책 해석 가능한 군집으로 묶음
  - 서울 강남3구 / 서울 기타 / 경기 인접핵심 / 경기 기타 / 수도권외
- 유출률 민감도(청년 이동 추정 편향 시나리오) 도입
- 정책 우선순위 매트릭스 산출
  - `Q1_고유출-고민원` 중심, 점수 기반 `A_즉시개입` 등급

## 3. 발표 시 주장 원칙
- "원인"이 아니라 "관측된 연관과 우선개입 후보"로 명확히 표현
- 민원 데이터는 청년 단독 민원이 아니므로 생활 마찰 신호로만 해석
- 통계적 유의성과 효과크기(계수/CI)를 분리 제시
