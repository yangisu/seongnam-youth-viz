    CHAPTER 03 · MAIN EVIDENCE

    신축/노후 지역군 중심 정책 근거

    여기서 `신축·재정비`, `노후·정체`는 개별 행정동을 묶은 지역군(생활권 클러스터)입니다. 즉 “지역 분류”가 맞습니다.
    개입 등급(A/B/C/D) 기준
    A: 고유출·지속유출·고민원 3개 플래그 동시 충족. B: 2개, C: 1개, D: 0개.
    A/B 등급 우선 생활권
    핵심 메인 도표: 개입 등급 위험도 맵
    X축: 6개월 순유출률(%), Y축: 순유출 월 비중(%), 점 크기: 민원강도, 색상: 개입등급. 점선은 정책 임계값입니다.
    개입 등급 분포
    핵심 도표: 지역군별 민원강도 분포
    X축=지역군, Y축=총인구 1천명당 민원강도. PC 화면에서 위험도 맵과 나란히 비교해 해석합니다.
    대체 관점 1: 지역군별 외부 유출 목적지 구성
    동일한 유출이라도 신축·재정비와 노후·정체 지역군은 도착 권역 구성이 다릅니다.
    목적지 편중 요약(HHI)
    지역군 요약 (민원/유출/A·B 비중)
    지역군 구성 행정동
    대체 관점: 지역군별 민원 토픽 구성 차이
    상관이 약할 때는 “수준(level)”보다 “구성(composition)” 차이를 본다는 관점입니다. 값(신축비중-노후비중)이 +면 신축·재정비에서 상대적으로 더 비중이 큽니다.
    신축/노후 축 정의 근거 (첨부 파일 반영)
    축 정의는 첨부된 standalone 결과의 핵심 라벨(유입 핫스팟/유출 핫스팟)을 기준으로 현재 민원 분석에 매핑했습니다.
