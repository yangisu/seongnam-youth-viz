# 성남시 청년 양극화 데이터 분석 

성남시 공공데이터 활용 시각화 경진대회 출품작 

기존 경제/상권 분석이 제외되고 **청년 인구의 모빌리티(Mobility), 민원 맥락(Complaint-context), 통계적 검증(Statistical rigor), 정책 우선순위(Policy prioritization)** 에 집중하도록 분석 로직이 전면 개편(V2)되었습니다.

분당·판교의 청년 유입과 수정·중원의 청년 유출이라는 **성남시 내부 양극화**를 데이터로 입증하고, 신축·재정비 권역과 노후·정체 권역 간의 구조적 격차를 민원 데이터 및 순유출률 통계로 규명합니다.

## 핵심 발견 (Claim Chain)

V2 데이터 분석을 통해 도출된 핵심 결론은 다음과 같습니다 (`seongnam-youth-v2/src/10_claim_chain.py` 참고):

1. **노후·정체 권역의 높은 민원 강도**: 노후·정체 권역의 총인구 1천명당 민원 강도는 신축·재정비 권역 대비 구조적으로 높습니다.
2. **청년 유출 압력 심화**: 노후·정체 권역은 신축·재정비 권역에 비해 청년 순유출 압력이 더 크게 작용하고 있습니다.
3. **분명한 민원 토픽 격차**: 신축 권역과 노후 권역 간의 민원 포트폴리오를 분석한 결과, 주거·환경 관련 핵심 토픽에서 유의미한 구성 격차가 발견되었습니다.
4. **순유출의 고착화**: 월별 순유출이 지속되는 정도(Negative month share)와 연간 청년 순유출률 사이에는 강한 양(+)의 통계적 상관관계가 존재합니다.
5. **즉시 개입 필요 지역 도출**: 분석 결과를 종합하여 단기적 개입이 시급한 정책 타겟(A_즉시개입 등급) 권역을 선정하고 우선순위를 제시합니다.

## 디렉토리 및 구조 (V2)

기존 분석 스크립트와 로직은 모두 새롭게 개편된 `seongnam-youth-v2/` 디렉토리 하위로 통합되었습니다. 기존 원본 데이터는 루트 디렉토리에 유지되며, V2 파이프라인에서 이를 자동 참조하여 분석을 수행합니다.

```text
seongnam-youth-viz/
├── data_by_region/               # 동별/월별 민원 상세 원본 데이터 (Excel)
├── data_by_type/                 # 유형별 민원 상세 원본 데이터 (Excel)
├── seongnam-youth-v2/            # ★ 메인 분석 파이프라인 (V2)
│   ├── src/                      # 데이터 처리, 통계 분석, 시각화 Python 스크립트 (00~10)
│   ├── data/
│   │   ├── processed/            # V2 파이프라인이 생성한 분석 결과 및 정제된 데이터
│   │   └── geojson/              # 성남시 행정동 경계 지도 파일
│   ├── outputs/                  # 생성된 인터랙티브 차트 및 HTML 웹 사이트 결과물
│   ├── docs/                     # 자동 생성되는 마크다운 리포트 및 문서
│   ├── run_all.ps1               # 전체 파이프라인 순차 실행 스크립트
│   └── README.md                 # V2 상세 안내 문서
└── README.md                     # 현재 문서
```

## 실행 방법

분석 및 시각화 전체 파이프라인은 `seongnam-youth-v2/` 폴더 내의 PowerShell 스크립트를 통해 일괄 실행할 수 있습니다. `run_all.ps1`은 원본 데이터 검증부터 전처리, 통계 분석, 가중치 최적화, 최종 HTML 웹 페이지 생성까지 전 과정을 순차적으로 자동화합니다.

```powershell
# 1. 작업 디렉토리 이동
cd seongnam-youth-v2

# 2. 가상환경 설정 및 필수 패키지 설치
python -m venv .venv
. .venv/Scripts/Activate.ps1
pip install -r requirements.txt

# 3. 전체 파이프라인 자동 실행 (00번 ~ 10번 스크립트 일괄 실행)
./run_all.ps1
```

```powershell
python src/08_iterative_optimizer.py --threshold 0.35 --max-iterations 4
```
